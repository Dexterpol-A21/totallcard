# Estructura SEO y Títulos de Páginas (TotallCard)

Este documento define la estructura oficial para las etiquetas `<title>` y `<meta name="description">` de cada ruta del sitio web para asegurar el mejor posicionamiento orgánico en Google (SEO).

## Reglas de la Estructura de Títulos
1. **Fórmula Estricta:** `[Palabra Clave Principal B2B] | TOTALLCARD`
2. **Propósito:** El cliente B2B (empresas/escuelas) busca soluciones exactas. Nadie busca la palabra "Totallcard" a menos que ya nos conozca, la gente busca "Impresión de Gafetes PVC". Por lo tanto, las palabras clave van SIEMPRE al inicio.
3. **Longitud Máxima:** No debe sobrepasar idealmente los 60 caracteres para que Google no los corte con puntos suspensivos `...`
